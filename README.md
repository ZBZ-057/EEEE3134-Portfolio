# EEEE3134 Portfolio

My coursework project for Applications of AI in EEE.

This repository will contain two versions of my personal webpage:
- AI-generated webpage
- AI-guided webpage

## Version 1: AI-Generated Webpage

[`ai-generated-page.html`](ai-generated-page.html) is a self-contained academic
portfolio with education, technical skills, four engineering projects, and contact
links. It uses embedded styles and illustrations, with no external dependencies.

To preview it locally, double-click `ai-generated-page.html` in File Explorer, or
run this command in PowerShell from the repository folder:

```powershell
Start-Process .\ai-generated-page.html
```

No installation or local server is required. Expand **Contributions & evidence**
on each project to read its details. Private reference documents are excluded by
`.gitignore` and are not linked from the webpage.
