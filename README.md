# EEE3134 Portfolio

My coursework project for Applications of AI in EEE.

This repository contains two versions of my personal academic and engineering portfolio website:

- **Version 1:** AI-Generated Webpage
- **Version 2:** AI-Guided Webpage

Both versions present my academic background, engineering interests, technical skills, selected projects, and contact information.

---

## Version 1: AI-Generated Webpage

[`ai-generated-page.html`](ai-generated-page.html) is an AI-generated academic portfolio.

It features:

- Academic background and education
- Technical skills
- Four engineering projects
- Contact information

The webpage uses embedded styles and illustrations.

## Version 2: AI-Guided Webpage

[`ai-guided-page.html`](ai-guided-page.html) is an AI-guided academic and engineering portfolio developed from my own design requirements, with AI assistance for implementation and refinement.

### Design Concept

The design combines two visual directions:

- **Dark-blue engineering technology:** A dark navy background, cyan accents, technical diagrams, and engineering-oriented visual elements.
- **Professional academic style:** A clear information hierarchy presenting academic background, technical interests, engineering experience, and project contributions.

### Main Sections

- Home – Personal introduction and engineering profile
- About – Academic and technical background
- Education – University and degree information
- Focus Areas – Main engineering interests
- Projects – Four selected engineering projects
- Skills – Technical skills and tools
- Contact – University email and GitHub profile

### Selected Engineering Projects

The projects are displayed in reverse chronological order:

1. Closed-Loop Control Design for a 50 W High-Frequency SMPS
2. Radar Speed Measurement System and Signal Conditioning Platform
3. LQR Control for a Parallel Wheel-Legged Balancing Robot
4. Intelligent Vision Recognition and Autonomous Line-Following Vehicles

Each project includes its objective, technical methods, tools, reported outcomes where available, and expandable technical details.

### Interactive Features

- Responsive webpage layout
- Section navigation and active navigation highlighting
- Expandable technical project details
- Conceptual engineering diagrams
- Keyboard-accessible navigation and controls

## How to Preview Locally

No installation or local development server is required.

You can preview either webpage by double-clicking its HTML file in File Explorer.

Alternatively, run the following commands in PowerShell from the repository folder:

**Version 1:**
```powershell
Start-Process .\ai-generated-page.html
```

**Version 2:**
```powershell
Start-Process .\ai-guided-page.html
```
